# llmstxt-lint

Zero-dependency linter for [`llms.txt`](https://llmstxt.org/) and `llms-full.txt` files: CLI, GitHub Action, pre-commit hook and SARIF output.

```bash
pip install git+https://github.com/Fuji643/llmstxt-lint
llmstxt-lint llms.txt
llmstxt-lint https://example.com/llms.txt --check-links
```
