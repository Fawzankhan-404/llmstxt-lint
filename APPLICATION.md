# Codex for Open Source – application notes

## How will you use API credits for your project? (paste this)

I'll use credits to run Codex as an automated reviewer on every pull request to llmstxt-lint, checking new lint rules against the llms.txt spec and asking for missing tests. I'll also automate maintainer work: triaging issues, reproducing bug reports into failing tests, and drafting fixes. For releases, Codex will draft changelogs and release notes and verify the version bumps before each tagged PyPI release.
